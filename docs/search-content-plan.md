# Search content plan

## Publishing cadence

Publish one useful article per week. Review Search Console once per month, using total non-branded impressions and the number of indexed editorial pages as the primary early health metrics. Do not change titles daily in response to short-term movement.

For every article:

1. Put the primary search phrase in the title, H1 and opening paragraph naturally.
2. Answer the query in the first two or three sentences.
3. Use question-shaped subheadings informed by live search results, autocomplete and Search Console queries.
4. Link legal claims to the Nigeria Tax Act or relevant official guidance.
5. Link to the calculator or `/tax-tools`, `/about`, and at least one related guide.
6. Add a link to the new article from an existing indexed page.
7. Record the verification event and source in `/tax-updates` when tax rules, not just prose, change.
8. After deployment, inspect the canonical public URL in Google Search Console and request indexing. Never request indexing for localhost or preview URLs.

## Monthly review

Export Search Console queries and pages monthly. Group queries by intent rather than chasing individual spelling variants. Update an existing page when it already satisfies the intent; create a new page only when the searcher needs a materially different answer. Keep a record of impressions, indexed pages, top query clusters and the next four-week publishing queue.
